# Univanta AI — جامعة حائل (مشروع تجريبي غير رسمي)

## نشر المشروع
1. ارفع محتويات هذا المجلد إلى **جذر** مستودع GitHub المرتبط بـ Netlify (وليس المجلد نفسه).
2. استبدل `index.html` و `netlify.toml` ومجلد `netlify/functions` بالنسخة الجديدة.
3. Netlify: Build command فارغ، Publish directory `.`، Functions directory `netlify/functions`.
4. لتفعيل الردود الحقيقية: أضف متغير بيئة سريًا `OPENAI_API_KEY` من إعدادات مشروع Netlify ثم أعد النشر. يمكن اختيار النموذج باستخدام `OPENAI_MODEL` (الافتراضي `gpt-4o-mini`). يتطلب استخدام API حسابًا وفوترة مناسبة. **لا تضع المفتاح في GitHub أو HTML**.
5. من دون المفتاح، تعمل الواجهة والحاسبات والجدول، لكن المحادثة تُظهر رسالة إعداد بدل اختلاق رد.

## حدود النسخة
- جميع خدمات ملف الطالب والدرجات والحضور الرسمي والتقارير هي صفحات توضيحية وليست مرتبطة بأنظمة الجامعة.
- التسجيل والجدول محليان وتجريبيان؛ لا يتم تسجيل مواد رسميًا.
- التواصل مع الموظفين ينشئ مسودة فقط ولا يرسلها لأي موظف.
- حاسبة المعدل تعتمد نقاط المواد التي يُدخلها الطالب على مقياس 4؛ راجع سلم الجامعة الرسمي.
- بيانات الجدول وسجل الغياب تُحفظ في التخزين المحلي على الجهاز نفسه ويمكن حذفها.
